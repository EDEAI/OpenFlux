这是 OpenFlux 1.0 的首个公开 Beta 版本，围绕 Project、多会话和长任务体验进行了一次重要升级。

## Project 与多会话

- 新增 Project，可为不同工作设置专属目录、项目说明和工作规则。
- 每个 Agent 和 Project 都可以建立多个独立会话，同时处理不同任务。
- 不同会话的聊天记录、任务进度和生成文件互不混淆。
- 切换会话后可继续原来的工作，后台任务完成时会显示未读提醒。
- 支持新建、重命名、切换和删除会话。

## 任务执行更灵活

- Agent 工作过程中可以继续补充要求，引导它调整当前任务。
- 可以把新任务加入待办队列，等待当前任务完成后自动执行。
- 队列任务支持修改、排序、立即执行、暂停、继续和删除。
- 停止当前任务后，后续任务不会意外继续执行。
- 重新打开应用后，不再出现任务持续数百小时或无法停止的情况。

## 执行过程更清楚

- Processing 更新时不再反复刷新和闪烁。
- 执行中仅展示最近 10 条动作，结束后可滚动查看全部步骤。
- 过程描述会说明实际检查、修改或生成了什么。
- 停止、失败、超时和等待确认等状态更加明确。
- 多个 Agent 协作时，可以更准确地看到各自的执行结果和状态。
- 减少因自行设定文件大小或格式目标而反复修改、长时间无法结束的问题。

## 日常使用体验

- 可选择每次操作都询问、自动处理低风险操作或使用完全访问权限。
- 需要确认时会展示操作内容和风险原因，同时隐藏敏感信息。
- Enter 直接发送，Shift+Enter 换行，并支持上传 `.doc` 文件。
- 增加用户消息快速导航，长对话中可以快速返回之前的问题。
- 长文档和复杂任务可以输出更完整的内容，减少过早中断。
- 支持直接生成本地 MP4 视频，浏览器录制回放也更加稳定。
