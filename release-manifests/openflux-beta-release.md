这是 OpenFlux 1.0 的首个公开 Beta 版本。从一次对话到完整项目，让多项工作并行推进，每一步都清晰可控。

## 一个 Project，装下整个工作

- 专属目录、项目说明和工作规则，打开就能接着做。
- 同一 Agent 或 Project 多会话并行，记录、进度和文件井井有条。
- 后台任务完成自动提醒，多个工作互不打扰。

## 任务不断线，节奏由你掌控

- 执行中随时补充要求，Agent 会按新方向继续。
- 新任务先排队，修改、排序、暂停或立即执行都由你决定。
- 停止更可靠，重新打开应用也不会出现虚假耗时。

## 每一步，看得清也控得住

- Processing 平滑追加，运行看最近 10 条，完成后查看全部。
- 描述直达实际结果，少说目的，多说做了什么。
- 确认、失败、超时和多 Agent 协作状态一目了然。

## 少些打扰，多些成果

- 三种操作确认方式按需选择，敏感信息自动隐藏。
- Enter 发送、`.doc` 上传和消息导航，让长对话更顺手。
- 长任务输出更完整，还能生成本地 MP4，浏览器回放更稳定。
