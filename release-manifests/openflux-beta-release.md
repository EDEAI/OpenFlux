这是 OpenFlux 1.0 的首个公开 Beta 版本，全面升级 Project、多会话与长任务体验。

## Project 与多会话

- 新增 Project，可设置专属目录、说明和工作规则。
- 每个 Agent 和 Project 支持多个独立会话。
- 会话记录、任务进度和生成文件互不混淆，后台完成后显示未读提醒。

## 任务执行更灵活

- 执行中可继续补充要求，也可将新任务加入待办队列。
- 队列任务支持修改、排序、立即执行、暂停、继续和删除。
- 停止任务后队列不会意外继续，重新打开应用也不会产生虚假耗时。

## 执行过程更清楚

- Processing 平滑追加；执行中显示最近 10 条，结束后可查看全部步骤。
- 过程描述聚焦实际完成的动作，减少重复说明。
- 停止、失败、超时、确认和多 Agent 协作状态更加明确。

## 日常使用体验

- 提供三种操作确认方式，并自动隐藏敏感信息。
- Enter 发送、Shift+Enter 换行，支持 `.doc` 上传和消息快速导航。
- 长任务输出更完整，支持本地 MP4 视频，浏览器回放更加稳定。
