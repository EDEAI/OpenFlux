## 文档概述

本文档面向 OpenFlux 终端用户，详细说明：
- 系统内置了哪些 **Agent（智能体）**
- 每个 Agent 拥有哪些 **工具能力**
- 用户应该如何用 **自然语言提示（Prompt）** 触发对应功能

> **无需记忆命令**：OpenFlux 会自动路由到合适的 Agent，用户只需自然描述需求即可。

---

## 一、Agent 概览

OpenFlux 默认配置了 **4 个内置 Agent**，系统会根据用户输入自动路由到最合适的 Agent。

| Agent ID | 名称 | 职责定位 |
|---|---|---|
| `default` | **通用助手 (General Assistant)** | 问答、聊天、知识查询、信息检索、文本翻译 |
| `coder` | **编程助手 (Coding Assistant)** | 编程、文件操作、代码执行、数据处理、文档生成 |
| `automation` | **自动化助手 (Automation Assistant)** | 浏览器操控、桌面自动化、定时任务、工作流、爬虫 |
| `image` | **绘图助手** | 文生图、AI 绘画、海报/插画/图标/Logo 生成、图生图 |

## 二、工具全览

OpenFlux 内置以下工具，按功能分为 6 大类：

### 网络工具
| 工具名 | 功能描述 |
|---|---|
| `web_search` | 互联网搜索（Brave / Perplexity 搜索引擎） |
| `web_fetch` | 抓取网页内容（自动提取正文，去除噪音） |
| `browser` | 浏览器自动化（导航、点击、填表、截图、上传文件） |

### 文件与系统工具
| 工具名 | 功能描述 |
|---|---|
| `filesystem` | 文件系统操作（读写、列目录、删除、复制、移动、监视） |
| `process` | 执行系统命令、Shell 脚本、终端操作 |
| `file_reader` | 读取 Office 文档（docx/xlsx/pptx/pdf/csv/epub/html）转换为文本 |
| `opencode` | 调用 AI 编程 Agent（agy/claude/codex/cursor） |

### 系统控制工具
| 工具名 | 功能描述 |
|---|---|
| `windows` | Windows 系统操作（应用管理、注册表、系统信息、PowerShell） |
| `desktop` | 桌面控制（键盘鼠标模拟、窗口操作、截屏） |

### 任务调度工具
| 工具名 | 功能描述 |
|---|---|
| `scheduler` | 设置定时提醒、周期任务、计划执行 |
| `workflow` | 保存和复用自动化工作流模板 |

### 通讯与文档工具
| 工具名 | 功能描述 |
|---|---|
| `email` | 收发邮件（SMTP/IMAP，支持读取、搜索、发送） |
| `office` | Office 文档创建/编辑（Word/Excel/PPT 处理） |
| `notify_user` | 向用户发送桌面通知 |

### 创意工具
| 工具名 | 功能描述 |
|---|---|
| `generate_image` | 文生图 / 图生图（AI 绘画） |

### 协作工具（内部使用，用户可感知）
| 工具名 | 功能描述 |
|---|---|
| `sessions_spawn` | 创建跨 Agent 协作会话（调度其他 Agent 并行执行任务） |
| `sessions_send` | 向协作会话发送消息或检查进度 |
| `sessions_search` | 在历史会话中检索内容 |
| `skill_store` | 技能市场（安装/卸载 Agent 技能扩展包） |

### 6.4 微信绑定（iLink）

OpenFlux 支持通过**腾讯官方 iLink Bot API** 接入微信个人号，绑定后可直接在微信私聊中与 AI 对话。

**绑定步骤：**

1. 打开 **设置 → 微信 iLink** 标签页
2. 点击 **"获取微信登录二维码"**
3. 用微信扫描二维码
4. 扫码成功后系统自动完成绑定（`accountId` 和 `token` 由服务端自动颁发保存）
5. 显示 **"已连接"** 即绑定完成

**消息策略配置：**

| 策略 | 说明 |
|---|---|
| **全部接受** | 所有人的私聊消息都转发给 Agent 处理 |
| **仅白名单** | 只有白名单中的用户 ID 才会被处理 |
| **关闭** | 停止接收微信消息 |

白名单模式下，在"白名单用户"输入框中每行填入一个微信 user_id（iLink user_id）即可。

> **注意**：目前仅支持**私聊**消息，群聊消息默认不处理。

### 6.5 工作流（Workflow）

工作流是将多个工具步骤编排成固定流程的自动化方案，适合需要重复执行的标准化任务。

#### 内置预设工作流

系统内置以下工作流，说出关键词即可自动触发：

| 工作流 ID | 名称 | 触发关键词 | 说明 |
|---|---|---|---|
| `project-init` | 项目初始化 | 初始化项目、创建项目 | 创建标准目录结构和配置文件 |
| `bug-fix` | 系统化修复 Bug | 修复bug、排查问题 | 定位→分析→修复→验证四步流程 |
| `code-review` | 代码审查 | 代码审查、review | 结构化代码质量审查 |
| `deploy-check` | 部署前检查 | 部署检查、上线检查 | 依赖/构建/配置的标准化检查 |
| `batch-file-ops` | 批量文件处理 | 批量处理、批量重命名 | 批量扫描和操作文件 |
| `daily-report` | 日报生成 | 写日报、生成日报 | 扫描工作文件并生成 Word 日报 |
| `data-extract` | 数据提取 | 数据提取、合并Excel | 多文件数据汇总到 Excel |
| `file-organize` | 文件整理 | 整理文件、文件分类 | 按类型自动归类文件 |
| `learn-skill` | 学习新技能 | 学习技能、安装技能 | 从技能市场下载并安装技能 |

**示例 Prompt：**
```
帮我写日报，工作目录是 D:\工作文件，输出到 D:\日报\今日日报.docx
整理一下 D:\下载 文件夹，按类型分类
查看目前有哪些可用的工作流
```

#### 创建自定义工作流

直接告诉 AI 你想创建的流程，AI 会自动编写模板并保存：

```
帮我创建一个工作流：每次运行先读取 config.json，
然后搜索最新的行业新闻，最后生成一份摘要报告保存到 output 目录
```

AI 会将其保存为可复用的工作流，之后直接说触发词即可再次执行。

> 自定义工作流无法覆盖内置预设工作流，ID 不能与预设冲突。

#### 查询工作流执行状态

```
查看刚才那个工作流的执行结果
查看工作流列表
```

## 七、使用技巧

**最佳实践：**

1. **描述目标，而非步骤**：说"帮我买一个充电宝"而不是"打开京东→搜索→点击→付款"
2. **提供上下文**：说"分析这份报告的财务部分"比"分析报告"更精准
3. **大任务分步**：复杂任务可以先说主要目标，AI 会自动拆解子任务
4. **拖入文件**：有相关文件时直接拖入，AI 会自动读取内容
5. **时间表达**：可以说"30分钟后"、"明天上午9点"、"每周一早上8点"

**需要避免：**

1. 不要说"帮我写一段代码（但不执行）"——直接说需求，AI 会写代码并执行验证
2. 不要提供过于模糊的指令，如"帮我处理数据"——说清楚数据在哪、要做什么处理
3. 不要担心多步骤——AI 会自动规划并执行，遇到问题会告知你

## 九、常见问题

**Q: 为什么 AI 没有使用浏览器工具？**  
A: 浏览器工具只在**自动化助手**中可用。编程助手（coder）、绘图助手等其他 Agent 的工具集中**不包含**浏览器，因此无法使用。如果你需要浏览器操作（打开网页、点击、抓取、截图等），请明确说出相关需求，系统会自动路由到自动化助手；或者直接说"切换到自动化助手"。

**Q: 定时提醒没有触发怎么办？**  
A: 检查 OpenFlux 是否在后台运行。定时任务需要 OpenFlux 保持运行状态。

**Q: 如何让 AI 记住我的偏好？**  
A: 直接告诉 AI 即可，系统会自动保存。只要你提到个人偏好、配置、计划等信息，AI 会立即调用记忆工具主动保存，无需特别说"帮我记住"。例如："我喜欢简洁的报告格式，不要用表格"。

**Q: 上传图片后 AI 看不到？**  
A: 图片理解需要当前使用的模型支持多模态能力。如果 AI 无法识别图片，可以尝试切换到支持视觉功能的模型（在设置中调整），或联系管理员确认当前模型配置。

**Q: 搜索结果不够新？**  
A: 在 Prompt 中加入时效词，如"**最新的**""**今天的**""**最近一周的**"，AI 会自动启用时间过滤参数（支持过去 24 小时/一周/一个月/一年）。例如："搜索最近 24 小时的 AI 新闻"或"今天有哪些科技热点"。
