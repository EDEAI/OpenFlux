# OpenFlux 1.0.1

OpenFlux 1.0.1 is the first stable bridge release for the signed, user-confirmed
automatic update flow.

## Highlights

- Added a lightweight update notice with one user confirmation, followed by signed
  download, installation, and restart without further participation.
- Kept the legacy release manifest for older clients; clients upgraded to 1.0.1 can
  use the signed updater feed for later releases.
- Added the presentation agent and PPTX/PDF generation workflow with scenario
  regression coverage.
- Improved multi-agent execution, goal reconciliation, activity tracking, and tool
  policy handling.
- Added direct open/reveal actions for local file links.
- Added Alibaba Cloud Model Studio (Qwen) provider support and refined the neutral
  visual theme.

The Apple Silicon and Intel packages are built and notarized separately by the
macOS release team. See `release-manifests/README-updater.md` for the architecture,
